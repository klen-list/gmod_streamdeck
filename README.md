# 🎛️ Garry's Mod StreamDeck Plugin

### ⚠️ WORK IN PROGRESS ⚠️

✨ Current abilities:
1. Run console commands

## 🔨 Installation
1. Clone repo
2. Build plugin: `npm install` and `npm run build`
3. Copy garrysmod folder to game folder with file replace
4. Done
